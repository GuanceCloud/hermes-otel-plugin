# v0.1.8

## Summary

`v0.1.8` rebuilds the metrics model around the OpenTelemetry GenAI metric set.

## What's Included

- Replaced legacy `gen_ai.agent.*` and `gen_ai.runtime.*` metrics with `gen_ai.workflow.duration`, `gen_ai.client.operation.duration`, and `gen_ai.client.token.usage`
- Stopped emitting aggregated usage metrics on `hermes_request` / `invoke_agent`
- Limited token usage metrics to model-call `input` and `output` buckets
- Added skill durations to `gen_ai.client.operation.duration` with `gen_ai.operation.name=skill` and `gen.ai.skill.name`
- Updated English and Chinese metrics and semantic mapping docs

## Validation

- `python -m unittest discover -s tests -v`
- `python -m compileall src tests`
