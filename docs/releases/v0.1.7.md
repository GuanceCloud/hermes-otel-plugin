# v0.1.7

## Summary

`v0.1.7` updates the installer restart strategy for Hermes gateway deployments managed by systemd.

## What's Included

- Tried `sudo systemctl restart hermes-gateway.service` first during install-time restart
- Kept `hermes gateway restart` as a fallback path
- Updated the English and Chinese install docs for the new restart order

## Validation

- `bash -n scripts/install.sh`
- `python -m unittest discover -s tests -v`
