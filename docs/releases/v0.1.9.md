# v0.1.9

## Summary

`v0.1.9` restores `gen_ai.agent.operation.count` and unifies trace-side result fields around `status`.

## What's Included

- Restored `gen_ai.agent.operation.count` for `chat`, `execute_tool`, and `skill`
- Added normalized `status` tags to operation count points, following `gtrace-ai-semantic-conventions`
- Replaced trace and log `outcome` fields with `status`, and replaced `tool_outcome` with `tool_status`
- Kept `final_status` and `tool_result_status` as separate fields
- Updated English and Chinese metric, trace, and semantic mapping docs

## Validation

- `python -m unittest discover -s tests -v`
- `python -m compileall src tests`
