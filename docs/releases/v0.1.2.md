# v0.1.2

## Summary

`v0.1.2` fixes `agent_version` so telemetry reports the real Hermes Agent version instead of the plugin version.

## What's Included

- Fixed `agent_version` tagging across traces, metrics, logs, and synthetic test telemetry
- Changed the version source to use the real Hermes Agent runtime version
- Added a fallback that reads `~/.hermes/hermes-agent/hermes_cli/__init__.py` when `hermes_cli.__version__` cannot be imported directly
- Kept `agent_runtime` as the built-in constant value `hermes`
- Added regression coverage for `agent_runtime` and `agent_version` on root spans, llm spans, tool spans, and subagent spans

## Notes

- `agent_version` now reflects the installed Hermes Agent version from the active Hermes runtime
- `plugin_version` remains the plugin's own package/release version and is separate from `agent_version`

## Validation

- `python3 -m unittest discover -s tests -v`
- Verified the resolver returns the local Hermes Agent version in the current environment
