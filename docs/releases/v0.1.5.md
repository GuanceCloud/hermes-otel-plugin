# v0.1.5

## Summary

`v0.1.5` normalizes skill telemetry fields, fixes the skill span hierarchy, and removes obsolete skill-source tags.

## What's Included

- Unified skill fields across `tool:skill_view` and `skill:*`:
  - `skill.name`
  - `skill.description`
  - `skill.path`
  - `skill_call_id`
  - `skill.source.type`
  - `skill.result_status`
  - `gen_ai.skill.*`
- Fixed the parent-child span chain to `llm -> tool -> skill`
- Removed the old `skill_source` field and standardized on `skill_call_id`
- Updated Chinese and English docs for the new skill field model

## Validation

- `python -m unittest discover -s tests -v`
- `python -m compileall src tests`
