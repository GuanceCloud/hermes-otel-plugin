# v0.1.5

## Summary

`v0.1.5` mainly cleans up skill-related telemetry fields and span relationships.

## What's Included

- Unified skill fields across `tool:skill_view` and `skill:*`
- Fixed the span hierarchy to `llm -> tool -> skill`
- Removed the old `skill_source` field and standardized on `skill_call_id`
- Added `gen_ai.skill.*` extension fields
- Updated the Chinese and English trace, metrics, and semantic mapping docs

## Validation

- `python -m unittest discover -s tests -v`
- `python -m compileall src tests`
