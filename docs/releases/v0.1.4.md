# v0.1.4

## Summary

`v0.1.4` aligns Hermes model-call telemetry with OpenTelemetry GenAI semantic conventions, improves provider error export, and renames the primary agent execution span to `invoke_agent`.

## What's Included

- Renamed the primary execution span:
  - old span name: `agent_run`
  - new span name: `invoke_agent`
  - `span_kind=agent` and `gen_ai.operation.name=invoke_agent` are retained
- Added GenAI content and request semantic fields on `llm` spans:
  - `gen_ai.input.messages`
  - `gen_ai.output.messages`
  - `gen_ai.system_instructions`
  - `gen_ai.tool.definitions`
  - `gen_ai.response.id`
  - `gen_ai.response.finish_reasons`
  - `gen_ai.output.type`
  - `gen_ai.request.choice.count`
  - `gen_ai.request.max_tokens`
  - `gen_ai.request.temperature`
  - `gen_ai.request.top_p`
  - `gen_ai.request.top_k`
  - `gen_ai.request.frequency_penalty`
  - `gen_ai.request.presence_penalty`
  - `gen_ai.request.seed`
  - `gen_ai.request.stop_sequences`
  - `gen_ai.request.stream`
- Added standard tool-call fields on `tool:*` spans:
  - `gen_ai.tool.call.id`
  - `gen_ai.tool.call.arguments`
  - `gen_ai.tool.call.result`
- Added current GenAI token semantic fields while retaining previous aliases:
  - `gen_ai.usage.cache_read.input_tokens`
  - `gen_ai.usage.cache_creation.input_tokens`
  - `gen_ai.usage.reasoning.output_tokens`
- Added OpenTelemetry GenAI client metrics:
  - `gen_ai.client.operation.duration`
  - `gen_ai.client.token.usage`
- Added `api_request_error` hook handling:
  - failed provider requests now write `error.type`, provider error details, HTTP status, retry information, and base URL
  - terminal API errors propagate to `hermes_request` and `invoke_agent`
  - finalized sessions with terminal API errors are marked `failed`
- Updated installer GitHub Release URL handling:
  - `OSS_ENDPOINT=https://github.com/GuanceCloud/hermes-otel-plugin/releases`
  - `latest` resolves to `.../releases/latest/download/...`
  - versioned installs resolve to `.../releases/download/vX.Y.Z/...`
- Added Chinese and English semantic field mapping documentation.

## Compatibility Notes

- Existing Hermes-specific fields and existing `gen_ai.agent.*` metrics are retained for dashboards, monitors, and queries that already depend on them.
- `gen_ai.input.messages` and `gen_ai.output.messages` are written as JSON strings because span attributes do not reliably preserve nested object arrays across all OTLP backends.
- The old span name `agent_run` is no longer emitted for new traces. Query by `span_kind=agent` or `gen_ai.operation.name=invoke_agent` when possible.
