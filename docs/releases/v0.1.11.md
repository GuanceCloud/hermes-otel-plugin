# v0.1.11

Fix missing `agent_runtime` labels on Hermes metrics.

## Changes

- Set `agent_runtime=hermes` on the shared OTLP Resource used by metrics, traces, and logs. All four metric families now carry the runtime identity automatically.
- Keep runtime identity controlled by the plugin; no user configuration is required.
- Document the resource attribute in English and Chinese and add a regression that collects real SDK metrics and checks their OTLP Protobuf resource.
- Install declared runtime dependencies in CI before running tests.

## Validation

All 39 unit tests pass, including installer regressions and SDK-to-Protobuf metric resource coverage. Real Hermes conversations and production receiver ingestion have not been verified for this release.

## Upgrade

Use the release installer with `v0.1.11` or `latest`, then restart Hermes to load the updated plugin. Existing telemetry configuration is preserved unless explicitly overridden.
