# v0.1.1

## Summary

`v0.1.1` adds Hermes session metadata fields to trace root spans and documents the field semantics and boundaries.

## What's Included

- Added session metadata export on `hermes_request` and `agent_run`
- Added `session_key` and structured session-derived fields:
  - `session_namespace`
  - `session_agent`
  - `session_channel`
  - `session_scope`
  - `session_channel_target`
- Added gateway-backed session timestamps and metadata:
  - `session_create_at`
  - `session_updated_at`
  - `session_chat_type`
  - `session_file`
- Added a session metadata resolver based on Hermes gateway session index data
- Updated Chinese and English trace documentation with a dedicated `Session Metadata` section

## Notes

- `session_file` currently represents the Hermes gateway legacy transcript path:
  - `~/.hermes/sessions/<session_id>.jsonl`
- `session_cwd` is still not emitted in this release because Hermes does not currently expose a stable, unified session-level cwd field
